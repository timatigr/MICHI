# Добавление контента

Контент лежит в `app/content/`, объединяется в учебный порядок в
`registry.py`. Всегда **повторяй формат соседних записей** в целевом файле
(он первоисточник — не выдумывай поля) и в конце прогоняй тесты.

## Кандзи → `app/content/kanji.py`

1. Добавь словарь в список `KANJI`. Поля — как у соседей: `char, meaning,
   on, kun, reading, examples [{w,r,ru}], mnemonic`; для составных знаков —
   `components: [{char, meaning}]`.
2. Включи знак в урок: либо в существующий `LESSONS[*]["kanji"]`, либо новый
   урок (id `j06`, `j07`… по порядку; `unit`, `title`, `subtitle`, `icon`,
   `intro`, `kanji:[...]`). Новый юнит — добавь в `UNITS`.
3. Прорисовка (навык `kanji_writing`) берёт черты из
   `app/content/kanjivg_kanji.json`. Для нового знака добавь его в
   `KANJI_CHARS` в `scripts/fetch_kanjivg.py` и перекачай
   (`.venv\Scripts\python scripts\fetch_kanjivg.py`). Без черт упражнение
   написания просто не появится — остальные навыки работают.

Инварианты (их стерегут `tests/test_kanji.py`):
- `reading` обязан совпадать с `examples[0]["r"]` (каноничное чтение);
- каждый `components[*].char` должен быть **уже введён как кандзи в более
  раннем уроке** (i+1, 6.3) — иначе тест упадёт;
- варианты в упражнении чтения должны быть уникальны (следствие — у разных
  знаков урока желательно разное `reading`).

Завершение урока создаёт **3 карточки на знак** (meaning/reading/writing) —
см. `srs_items_for_lesson` в `registry.py`.

## Слово N5 → `app/content/vocab_n5.py`

1. Добавь запись в `WORDS`: `{id, kana, romaji, ru}` (+ `note` по желанию).
   `id` — уникальный латиницей.
2. Включи `id` в `words` нужного урока `LESSONS` (или заведи новый урок
   `v13`… с `unit, title, subtitle, icon, words:[...]`).
3. **i+1 соблюдается автоматически**: `registry.py` вычисляет `requires` из
   каны слова — урок откроется, лишь когда вся его кана пройдена. Поэтому
   пиши слова только из уже существующей каны (или сознательно двигай урок
   позже в курсе). Слово даёт 2 карточки (jp→ru, ru→jp).

## Новый тип урока / карточки

Точка расширения — `srs_items_for_lesson` в `registry.py` (какие карточки
создаёт урок) и `make_lesson_steps` / `review_exercise` в `app/exercises.py`.

## После любых правок — обязательно

1. Тесты: `.venv\Scripts\python -m pytest -q` — должны пройти все
   (инварианты SRS, реестра, i+1, кандзи).
2. Если правил фронт или хочешь увидеть контент вживую — `/ui-check`.
3. Открой приложение и пройди новый урок (`run.bat`, http://127.0.0.1:8000).
