Звуки интерфейса (нажатия, вердикт ответа)
===========================================

Источник:  Kenney — «Interface Sounds»
           https://kenney.nl/assets/interface-sounds
Лицензия:  Creative Commons Zero (CC0 1.0) — общественное достояние.
           Атрибуция не требуется; указана из вежливости.
           https://creativecommons.org/publicdomain/zero/1.0/

Зеркало, из которого скачаны файлы (тоже CC0):
           https://github.com/Calinou/kenney-interface-sounds

Используемые файлы (курированы по метрикам мягкости — ZCR/длительность/атака;
хвостовая тишина у новых подрезана):
  bong_001, click_005, back_002, switch_006, drop_003, select_002, glitch_001
    — звук нажатия (выбор в настройках);
  confirmation_001 — верный ответ; error_008 — ошибка (мягкий низкий).
Старые варианты (tick_002, click_002, pluck_002, glass_002, switch_002,
error_002) оставлены для совместимости с сохранёнными настройками.
