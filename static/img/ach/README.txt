Свои картинки для достижений (drop-in слоты)
============================================

Хотите вместо кавай-SVG показывать «настоящий» аниме-арт на достижение —
положите сюда картинку с именем <id>.png, где <id> — идентификатор достижения
из app/gamification.py.

Примеры имён файлов:
  first_lesson.png   — Первый шаг
  first_kanji.png    — Первый кандзи
  gate_first.png     — Врата открыты
  streak_7.png       — Неделя в строю
  hiragana_done.png  — Хирагана покорена
  level_5.png        — Бывалый
  ... (полный список id — в ACHIEVEMENTS в app/gamification.py)

Как это работает
----------------
* Картинка автоматически перекроет встроенный SVG — ни манифестов, ни правок
  кода. Чего здесь нет — тихо падает обратно на кавай-SVG.
* Показывается только у ОТКРЫТЫХ достижений (закрытые остаются силуэтом).
* Формат: квадрат (1:1), оптимально 320×320 px и больше, PNG (можно с
  прозрачностью). Картинка обрезается по центру под скруглённую плитку.
* Лёгкие файлы (≤150 КБ) — приятнее: грузятся лениво в момент показа.

Откуда брать арт
----------------
Свой рисунок, легально лицензированный пак или генерация
(напр. твоим ключом Gemini, модель gemini-2.5-flash-image). Случайные картинки
из интернета лучше не брать — копирайт.
