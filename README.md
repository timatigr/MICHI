# MICHI（道）— прототип core loop

Рабочий прототип платформы изучения японского по [SRS.md](SRS.md):
курс хираганы + интервальные повторения на алгоритме **FSRS v6**.

## Запуск

```
run.bat
```

и открыть **http://127.0.0.1:8000** в браузере.

(Сервер: FastAPI + uvicorn из локального окружения `.venv`.
Пересоздать окружение: `python -m venv .venv && .venv\Scripts\pip install -r requirements.txt`.)

## Что реализовано (ссылки на разделы SRS.md)

| Что | Раздел спеки |
|---|---|
| Курс хираганы: 104 графемы, 17 микроуроков по рядам годзюон, мнемоники, дакутэн/ёон/сокуон | 2.1 |
| Курс катаканы: 104 графемы, 18 уроков, гайрайго-слова, правило долготы ー, «катакана-ад» (シ/ツ, ソ/ン, ク/ワ/フ) | 2.2 |
| Лексика N5: 4 тематических юнита (Знакомство, Числа и время, Еда и напитки, Дом и быт) — 110 слов в 12 микроуроках; раздельные SRS-карточки JP→RU и RU→JP с независимыми интервалами; упражнения: выбор перевода, обратный выбор, аудио→значение, сборка слова | 2.5, 5.2 (№ 8, 9, 12) |
| Слова в уроках только из изученной каны (принцип i+1, проверяется автоматически) | 1.5, 2.1 |
| Парные «ловушки» похожих знаков (ぬ/め, わ/れ/ね, は/ほ…) | 2.1 |
| SRS на FSRS: learning-шаги 1→10 мин, состояния, post-lapse | 4.1, 4.2 |
| Авто-оценка ответов по времени (p25/p75 пользователя) | 4.2 |
| Пиявки (≥6 ошибок → пометка, показ мнемоники) | 4.2 |
| Очередь: просроченные по риску забывания → новые; дневные лимиты (12 новых / 150 повторений) | 4.4 |
| 6 типов упражнений каны: распознавание, звук→знак, **прописи**, сборка слова, дакутэн, ловушки | 5.1 (№ 1–5, 7) |
| Рукописный ввод с проверкой черт: число → порядок → направление → форма; режимы трассировка/по памяти | 6.7 |
| Статистика: retention, активность, прогноз нагрузки, трудные знаки | 4.3, 4.5 |
| Серия дней (streak) | 8.2 |
| Палитра традиционных японских цветов | 11.4 |
| Журнал ответов append-only (состояние SRS восстановимо из журнала) | 12.6, 13.2 |

Озвучка: по умолчанию — **нейроголоса Microsoft через Edge TTS**
(Нанами / Нанами-тян «кавайный» вариант / Кэйта; нужен интернет; файлы
кэшируются в `tts_cache/`), запасной вариант — голос браузера (Web
Speech API). Дополнительно поддерживается **VOICEVOX** — бесплатный
локальный движок аниме-голосов (Дзундамон, Сикоку Мэтан и др.):
установите его с https://voicevox.hiroshiba.jp/ и запустите — голоса
автоматически появятся в списке (движок слушает 127.0.0.1:50021).
Источник, голос, громкость и скорость настраиваются через ⚙ в шапке;
при недоступности сети происходит фолбэк на браузерный голос.

Данные черт для прописей — [KanjiVG](https://kanjivg.tagaini.net/)
(© Ulrich Apel, лицензия CC BY-SA 3.0), уже скачаны в
`app/content/kanjivg_kana.json` (переcкачать: `scripts/fetch_kanjivg.py`).

## Структура

```
app/
  main.py              — FastAPI: API уроков, SRS, статистики, озвучки
  db.py                — SQLite-схема (упрощённый раздел 12)
  srs_engine.py        — FSRS: оценка, очередь, лимиты, прогноз
  exercises.py         — генераторы 6 типов упражнений + сценарии уроков
  tts.py               — нейронная озвучка (Edge TTS) с дисковым кэшем
  content/hiragana.py  — контент хираганы: знаки, уроки, слова, ловушки
  content/katakana.py  — контент катаканы (гайрайго, «катакана-ад»)
  content/vocab_n5.py  — лексика N5: 4 юнита, 110 слов
  content/registry.py  — объединение курсов в общий учебный порядок
  content/kanjivg_kana.json — черты каны (KanjiVG, CC BY-SA)
static/                — веб-интерфейс (vanilla JS, без сборки)
  tracing.js           — канва рукописного ввода с проверкой черт
michi.db               — данные пользователя (создаётся при первом запуске)
```
