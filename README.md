# MICHI（道）— прототип core loop

Рабочий прототип платформы изучения японского по [SRS.md](SRS.md):
путь N5 (кана → лексика → кандзи → грамматика) на интервальных
повторениях по алгоритму **FSRS v6**.

## Запуск

Первый раз — установка окружения (создаёт `.venv` и ставит зависимости):

```
setup.bat
```

Дальше — запуск (сам откроет браузер на **http://127.0.0.1:8000**):

```
run.bat
```

Нужен Python 3.10+ ([python.org](https://www.python.org/downloads/); при
установке отметьте «Add Python to PATH»). Сервер — FastAPI + uvicorn из
локального `.venv`. Для разработки с автоперезагрузкой — `run-dev.bat`.

ИИ-разбор ошибок («Сэнсэй», раздел 7.2): по умолчанию **выключен**. Поддержаны
два провайдера (абстракция `LlmProvider`, 7.1), задаётся ключом перед запуском:

- **Gemini (бесплатно)** — `set GEMINI_API_KEY=...` (ключ без карты на
  [aistudio.google.com/apikey](https://aistudio.google.com/apikey)), модель
  Gemini Flash;
- **Claude** — `set ANTHROPIC_API_KEY=sk-ant-...` (ключ с
  [console.anthropic.com](https://console.anthropic.com/settings/keys)), модель
  Haiku.

Затем `run.bat`. Провайдер определяется автоматически по заданному ключу
(или явно через `MICHI_AI_PROVIDER=gemini|claude`); модель переопределяется
`MICHI_GEMINI_MODEL` / `MICHI_CLAUDE_MODEL`. Под неверным ответом появляется
кнопка «🧠 Разобрать ошибку»; запрос уходит только по нажатию, готовые разборы
кэшируются в `ai_cache/` (по «провайдер/модель × ошибка × упражнение»). Без ключа
кнопка не показывается, курс работает как обычно. Страховка по бюджету (задел под
продакшн-квоты, 7.1/16.1): `MICHI_AI_DAILY_LIMIT` — лимит обращений в сутки (по
умолчанию 200; кэш-разборы квоту не тратят), `MICHI_AI_ENABLED=0` — выключить ИИ
даже при ключе. Активный провайдер и остаток квоты видны в ⚙ настройках.

Озвучка: по умолчанию — **нейроголоса Microsoft через Edge TTS**
(Нанами / Нанами-тян «кавайный» вариант / Кэйта; нужен интернет; файлы
кэшируются в `tts_cache/`), запасной вариант — голос браузера (Web
Speech API). Дополнительно поддерживается **VOICEVOX** — бесплатный
движок аниме-голосов (Дзундамон, Сикоку Мэтан и др.); синтез серверный,
браузер ходит только в `/api/tts`:

- **локально**: установите движок с https://voicevox.hiroshiba.jp/ и
  запустите — голоса автоматически появятся в списке (127.0.0.1:50021);
- **на публичном сайте**: поднимите рядом контейнер
  `voicevox/voicevox_engine` и укажите `MICHI_VOICEVOX_URL` (готовый
  пример — `docker-compose.yml`) — аниме-голоса получат **все посетители,
  ничего не устанавливая**. Голоса — по условиям персонажей VOICEVOX
  (кредит вида «VOICEVOX:ずんだもん»).

Источник, голос, громкость и скорость настраиваются через ⚙ в шапке;
при недоступности сети происходит фолбэк на браузерный голос.

Данные черт для прописей — [KanjiVG](https://kanjivg.tagaini.net/)
(© Ulrich Apel, лицензия CC BY-SA 3.0), уже скачаны в
`app/content/kanjivg_kana.json` (переcкачать: `scripts/fetch_kanjivg.py`).

  content/verbs.py     — глаголы N5 и спряжение (ます/ました/ません/て)

  tracing.js           — канва рукописного ввода с проверкой черт

Проверка веб-интерфейса в headless-браузере: `.venv\Scripts\python scripts\ui_check.py`.

## Публичный хостинг (анонимные сессии)

Локально это однопользовательское приложение, но его можно выложить общим сайтом:
у каждого посетителя свой прогресс **без регистрации**. На первом визите выдаётся
анонимный идентификатор и кладётся в cookie, подписанную серверным секретом
(см. [app/identity.py](app/identity.py)); данные каждого пользователя — отдельная
база `data/users/<uid>.db` (см. [app/db.py](app/db.py)). База заводится лениво, на
первой записи, — простой визит/бот файлов не плодит. Экспорт/импорт прогресса
охватывают ровно «мой» прогресс и не могут затронуть чужой.

Переменные окружения для прода:

- `MICHI_SECRET_KEY` — секрет для подписи cookie (**обязателен в проде**; иначе
  генерируется и кладётся в `data/secret.key` — пропадёт вместе с томом, и все
  разлогинятся). Если в прод-режиме (`MICHI_COOKIE_SECURE=1`) он не задан, сервер
  пишет об этом WARNING при старте. Задайте постоянный:
  `fly secrets set MICHI_SECRET_KEY=$(openssl rand -hex 32)`.
- `MICHI_COOKIE_SECURE=1` — ставить cookie только по HTTPS (включать за TLS).

Защита от злоупотреблений на публичном сайте:

- **Рейт-лимит на `/api/*` по IP** включён по умолчанию (in-memory, для одной
  машины — см. [app/ratelimit.py](app/ratelimit.py)): режет поток запросов без
  cookie, которым бот плодил бы per-user базы и забивал диск. Для живого
  пользователя незаметен. `MICHI_RATE_MAX=N` (запросов за окно, по умолч. 60),
  `MICHI_RATE_WINDOW_SEC=N` (окно, по умолч. 10), `MICHI_RATELIMIT_ENABLED=0` —
  выключить. IP берётся из `Fly-Client-IP`/`X-Forwarded-For`, поэтому **на проде
  обязателен обратный прокси** (он ставит эти заголовки и не даёт их подделать).
  За несколькими инстансами лимит надо выносить на прокси/общий стор.
- `MICHI_AI_DAILY_LIMIT=N` — лимит ИИ-разборов **на пользователя** в сутки (по
  умолчанию 200; кэш не тратит квоту), `MICHI_AI_GLOBAL_DAILY_LIMIT=N` — общий
  потолок на всех (страховка бюджета владельца).
- `MICHI_TTS_ENABLED=0` — выключить серверную озвучку (Edge TTS под потоком
  людей троттлит, кэш растёт): фронт сам перейдёт на браузерный голос.
- `MICHI_VOICEVOX_URL=http://voicevox:50021` — адрес движка VOICEVOX для
  серверных аниме-голосов (см. `docker-compose.yml`); не задан — пробуется
  локальный 127.0.0.1:50021, при недоступности голоса просто не показываются.
- Заброшенные пустые базы (зашёл-потыкал-ушёл, боты) **подчищаются автоматически**:
  при старте и далее раз в сутки внутри процесса (`MICHI_CLEANUP_DAYS`, по умолч.
  30; `MICHI_CLEANUP_ENABLED=0` — выключить). Базы с прогрессом не трогаются.
  Скрипт `scripts/cleanup_users.py [дней]` остаётся для ручного/cron-запуска.
- **Серверные бэкапы всего прогресса снимаются автоматически** (при старте и
  далее раз в сутки): консистентный снимок всех баз через SQLite backup API +
  `secret.key` → `data/backups/michi-data-*.tar.gz` с ротацией
  (`MICHI_BACKUP_KEEP`, по умолч. 14; `MICHI_BACKUP_ENABLED=0` — выключить).
  Локальный архив не переживёт потерю тома, поэтому задайте `MICHI_BACKUP_S3_*`
  (endpoint/bucket/ключи — см. [app/backup.py](app/backup.py)) — архив будет
  дополнительно уезжать offsite в любое S3-совместимое хранилище (Cloudflare R2,
  Backblaze B2, AWS S3…), подпись SigV4 на stdlib, без boto3. Ротацию удалённых
  копий — lifecycle-политикой бакета: ключу с сервера прав на удаление лучше не
  давать. Ручной прогон: `python scripts/backup_data.py`. Восстановление:
  `tar -xzf michi-data-*.tar.gz -C data` на новом томе.
- **Метрики владельца** — `python scripts/owner_stats.py [--days N] [--json]`:
  офлайн-агрегация по базам пользователей (DAU, retention D1/D7/D30, воронка
  уроков, сессии, точность). Базы открываются read-only; на фронте по-прежнему
  ни аналитики, ни трекеров.
- **Заголовки безопасности** ставятся на каждый ответ автоматически (настройки не
  нужны): CSP под ресурсы приложения (только свой origin — шрифты self-hosted,
  внешних запросов нет; фрейминг запрещён),
  `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options`, `Permissions-Policy`;
  `Strict-Transport-Security` (HSTS) — только при `MICHI_COOKIE_SECURE=1` (за TLS).

> Перенос личного локального прогресса (старый `michi.db`) на анонимный
> аккаунт: откройте сайт, в ⚙ → «Импорт» выберите свой `michi.db` — он валиден
> как резервная копия и привяжется к текущему браузеру.

## Деплой (Docker)

Самый простой путь — compose с аниме-озвучкой для всех посетителей
(файл `docker-compose.yml` в корне; секрет — в `.env`):

```bash
echo "MICHI_SECRET_KEY=$(openssl rand -hex 32)" > .env
docker compose up -d
```

Либо один контейнер без VOICEVOX:

```bash
docker build -t michi .
docker run -d --name michi -p 8000:8000 \
  -e MICHI_SECRET_KEY="$(openssl rand -hex 32)" \
  -e MICHI_COOKIE_SECURE=1 \
  -e MICHI_TTS_ENABLED=0 \
  -v michi-data:/app/data \
  michi
```

`michi-data` (том на `/app/data`) — это весь пользовательский прогресс. Сервер
сам снимает суточные архивы в `data/backups/` на этом же томе, но от потери
тома они не спасают — настройте offsite через `MICHI_BACKUP_S3_*` (см. выше).
`MICHI_SECRET_KEY` **обязателен и постоянен**: при его смене все cookie
инвалидируются и пользователи теряют доступ к своему прогрессу.

TLS и рейт-лимиты — на reverse-proxy перед контейнером. Пример для Caddy
(автоматический HTTPS + ограничение частоты тяжёлых ручек):

```
michi.example.com {
    reverse_proxy localhost:8000
}
```

Готовые PaaS (Fly.io / Render / Railway) собирают этот же `Dockerfile`; не забудьте
прокинуть `MICHI_SECRET_KEY`, `MICHI_COOKIE_SECURE=1` и постоянный том на `/app/data`.
